# StoryForge i18n 维护指南

> 版本：1.0.0 · 更新：2026-08-26 · 状态：基础设施已存在，UI 尚未全量迁移

## 当前实现

- `src/i18n/index.ts` 提供零依赖 `t()`、`useTranslation()`、`setLang()` 和 `getLang()`。
- `src/i18n/locales/zh-CN.ts` 与 `en.ts` 保存已迁移文案。
- 语言选择持久化在本机；缺失 key 回退默认语言。
- `tests/registry/i18n.test.ts` 守护翻译可用、回退和语言包 key 对齐。

## 使用

```tsx
import { useTranslation } from '../i18n'

function Toolbar() {
  const { t, lang, setLang } = useTranslation()
  return <>
    <button>{t('common.save')}</button>
    <button onClick={() => setLang(lang === 'zh-CN' ? 'en' : 'zh-CN')}>
      {lang === 'zh-CN' ? 'EN' : '中'}
    </button>
  </>
}
```

非组件代码使用 `import { t } from '../i18n'`。

## 增量迁移规则

1. 按 `<产品或领域>.<语义>` 命名，不按组件文件名命名。
2. 新增中文 key 时同步英文 key；测试必须通过。
3. 不在同一界面混用翻译 key 与复制的平行常量。
4. 大语言包按产品/领域拆分，在入口合并，保持调用方稳定。
5. 只有出现复数、复杂插值、远程语言包或按需加载等真实需求时才评估更换实现；先保持 `t(key)` API 兼容。

优先迁移公共导航、设置/数据安全、错误与恢复提示，再按当前路线图迁移正在施工的产品。不要为尚未进入开发阶段的实验页面提前进行大规模翻译重构。
