# 世界引擎上层产品契约

> 版本：1.0.0 · 生效：2026-08-26 · 对应总纲：§6、阶段 E

## 1. 共通纵切面

跑团、角色聊天、AI 小镇和文字游戏都必须是完整垂直产品：

```text
选择并锁定 WorldRelease
→ 收集产品配置、参与者、体验目标和限制
→ 与产品主 Agent 会谈并确认 Brief
→ 冻结生产计划、预算和完成条件
→ 内容 / 规则 / 媒资并行生产
→ 自动组装、绑定、验证和有界修复
→ 形成不可变 ProductRelease
→ 运行 / 游玩 / 聊天
→ 在产品私域内保存和增量演化
```

每一阶段有明确表/契约、状态机、Agent/Skill 或确定性服务、错误恢复、运行证据和验收。一个“生成 Agent + 运行 Agent”的薄页面不算完整产品。

## 2. 体验目标

用户可以选择：

- **有界体验**：目标时长、章节/场景数、分支宽度、结局数、难度和收束方式；生产阶段验证体验能结束。
- **持续体验**：不预设最终终点，由有限回合/章节持续演化；用户可暂停、总结、继续或要求结局。

持续体验仍是一系列有限 durable run，每轮有预算、checkpoint、恢复和停止条件。

## 3. 媒资生产

主 Agent 根据产品计划产生 media requirements：角色立绘、场景、地图、UI、音乐、环境音、音效、配音或视频。媒资分支生成候选、选择、修复、绑定和版本；组装器验证每个消费位置和 license/provenance。

媒资由产品 production/build/release 拥有。共享 media/blob 层只是存储和生成设施。用户可以查看和替换，但正常流程不要求逐张下载再手工绑定。

## 4. 跑团

跑团至少包含：

- 规则集、人数、玩家、角色卡、技能、资源和判定；
- 初始情景、目标、队伍、阵营与关系；
- AI KP 主持、场景导演、NPC、掷骰和后果；
- 玩家私密信息、KP 信息、分队/并行场景和可见性；
- 节奏、线索、公平性、安全工具与精彩度控制；
- 长期战役记忆、回合/场景事件、存档、回放和恢复；
- 媒资、campaign build、release 与可选在线房间。

AI KP 每次只接收该参与者/队伍可见信息和主持所需私有信息；不能用前端隐藏代替数据隔离。判定、骰子、权限和状态更新由确定性服务执行，模型叙述结果。

## 5. 角色聊天与 AI 小镇

### 5.1 角色聊天

单角色和多角色聊天共享人格/关系基础，但需要场景、说话轮次、可见信息、长期记忆、关系变化、用户身份、重启恢复和角色一致性。多人聊天由导演决定谁发言，不让所有角色每轮机械回复。

### 5.2 AI 小镇

AI 小镇是在多角色之上的独立产品规模，增加：世界时间、地点、日程、需求、资源、群体关系、自治行动、事件传播、离线演化和多主体调度。角色不在场时的信息不能自动成为其记忆。

聊天产品和 AI 小镇有共享角色/记忆设施，但各自拥有 production、release、session 和状态机，不能由一个膨胀组件用模式开关承担。

## 6. 文字游戏

### 6.1 文字冒险

核心循环是情境 → 选择/行动 → 判定 → 状态/资源变化 → 新情境。需要可探索内容、任务、资源、失败/结局和可回放事件。

### 6.2 AVG

核心是场景、对白、演出、选项、分支和视听呈现。生产要生成脚本、立绘/表情、背景、CG、音乐、音效和 UI 绑定；运行强调阅读节奏、历史、存档和分支结局。

### 6.3 文字开放世界

核心是持续世界状态、地点探索、动态任务、角色自治、时间推进和开放演化。需要区域/任务导演、世界状态分区、按需模拟和长程事件；不能无限展开全部世界。

分类以真实不同的数据和玩法循环为准。共享 production/runtime 不得把所有产品压成同一个 schema 加 `type` 字段。

## 7. 私域演化

用户试玩/聊天后可提出增量目标。系统基于当前 ProductRelease + 私域 session 规划下一次生产或运行扩展，检查兼容、迁移和旧存档。衍生事实默认只属于该实例。

```text
用户演化目标
→ 影响分析与新 Brief
→ 增量内容/规则/媒资
→ 兼容验证
→ 新 ProductRelease 或 session checkpoint
```

世界引擎不接收自动反馈。多个用户引用同一个世界时，其产品和运行数据互相隔离。

## 8. 统一完成判据

- 只读锁定 WorldRelease，缺能力时明确补充策略；
- 用户可完成配置、会谈、一次开始指令和可见进度；
- 内容/规则/媒资生产、组装、验证、预览和发布端到端；
- 有界体验能结束，持续体验能有限循环、暂停和恢复；
- release 不可变，运行不改世界；
- 多用户、角色、队伍、世界和产品实例隔离；
- provider、非法输出、断网、刷新、stale、预算和媒资失败有恢复；
- 真实可玩/可聊 E2E 与人工体验验证通过。
