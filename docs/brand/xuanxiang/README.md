# 悬象品牌初稿

## 核心概念

“悬星浑仪”以极简几何组合三个含义：

- 断开的天球外环：星辰天象长悬天际，也代表持续开放、演化的世界。
- 斜向浑仪轨道：StoryForge 的世界引擎与多产品运行轨道。
- 中心四向星火：最初的创意种子、故事熔炉，以及从世界向多种产品生长的出口。

公司品牌使用“悬象 / XUANXIANG”，产品联合场景使用“悬象 + StoryForge · 故事熔炉”。公司标识不直接绑定单一产品名称，便于未来扩展新的产品线。

## 使用边界

- 图形最小显示尺寸建议为 24 像素；24–40 像素时优先使用纯图形。
- 标准版周围至少保留一个中心星火宽度的安全空间。
- 不旋转图形，不改变轨道比例，不使用超过三种品牌色。
- 正式工商和大规模商业使用前，仍需完成商标近似检索与字体商用授权核对。
